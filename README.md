# Cursor Interactive Demo

An interactive product tour of Cursor.

1. Opens on the Cursor logo
2. Click anywhere — the logo zooms into white
3. A Cursor IDE layout appears with glowing hotspots
4. Click any hotspot to learn about that feature

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).
